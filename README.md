# Kutira-Kushala 🏠📱

Kutira-Kushala is an Android-based mobile application developed using Kotlin and Firebase to support small-scale, home-based, and cottage industry entrepreneurs. The application provides a simple digital platform where local artisans and small business owners can showcase their products, connect directly with customers, and improve their business visibility without depending on intermediaries.

---

## 🌟 Features

* 🔐 User Authentication (Login & Register)
* 🏢 Business Profile Management
* 📦 Product Upload & Management
* 🖼 Product Image Upload using Firebase Storage
* 📋 Product Listing using RecyclerView
* 📞 Direct Call Feature for Customers
* 🔄 Availability Toggle for Sellers
* ☁ Firebase Firestore Database Integration
* 🎨 User-Friendly Interface

---

## 🛠 Technology Stack

* Kotlin
* Android Studio
* Firebase Authentication
* Firebase Firestore
* Firebase Storage

## 📱 Project Objective

The objective of Kutira-Kushala is to digitally empower local artisans, homemakers, and cottage industry entrepreneurs by providing a simple and accessible platform to showcase and promote their products.

## ⚙ Setup Instructions

```bash id="mvbx4p"

```

2. Open project in Android Studio

3. Connect Firebase project

4. Add `google-services.json` inside the `app/` folder

5. Sync Gradle files

6. Run the application on emulator or Android device
